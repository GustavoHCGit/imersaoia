# Agents.md — contexto didático

Este arquivo demonstra a organização de contexto apresentada na Imersão Alura.

## Goal

Reproduzir, com fins educacionais, o StudyFlow e o fluxo de um agente que transforma preferências de estudo em um plano e uma agenda importável.

## Context

A aplicação é React + TypeScript. O StudyFlow usa estado local e localStorage. O agente deste projeto é uma implementação determinística no navegador para demonstrar o fluxo sem exigir uma chave de API.

## Constraints

- Não afirmar vínculo oficial com a Alura.
- Não atribuir ao participante autoria exclusiva dos materiais da imersão.
- Priorizar requisitos claros, revisão humana e transparência sobre as adaptações.
- Manter a experiência utilizável em telas pequenas.

## Done When

- É possível criar, editar, concluir e excluir objetivos no StudyFlow.
- Os objetivos permanecem após atualizar a página.
- É possível gerar um plano personalizado e exportar um arquivo `.ics`.
- A interface explica os conceitos e aponta as fontes consultadas.
